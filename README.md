# Прогнозирование стоимости недвижимости

**Автор:** Билалова И.  
**Группа:** 23П-2

## Описание проекта

Проект посвящён анализу данных о недвижимости и построению модели машинного обучения для прогнозирования стоимости объектов. В качестве алгоритма регрессии используется `CatBoostRegressor`, который строит ансамбль деревьев решений и позволяет работать с категориальными признаками.

В ходе работы выполняются очистка и подготовка данных, обработка валют, формирование признаков, обучение модели, получение прогнозов и оценка качества предсказаний.
